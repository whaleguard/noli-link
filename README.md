# 놀이링크 · 위드메모리

카톡방에 붙이면 바로 노는 링크. 사다리·룰렛·투표부터 두더지 잡기까지.

- 받은 사람은 링크만 누르면 바로 참여합니다. 가입·로그인·설치 없음
- 링크를 가진 사람만 들어올 수 있습니다. 목록·검색 없음
- 모든 링크는 만든 지 24시간 뒤 종료됩니다
- 서버에 아무것도 저장하지 않습니다. 방 내용은 링크의 `#` 뒷부분에만 들어 있고, 이 부분은 서버로 전송되지 않습니다

### 동작 방식
- **정하기**: 링크에 참가자·결과·시드가 들어 있어 누가 열어도 같은 결과
- **투표·게임 (기록 이어달리기)**: 참여하면 내 기록이 더해진 새 링크가 생기고, 그걸 방에 다시 올립니다. 두 사람이 같은 링크에서 동시에 참여해 링크가 갈라지면 "기록 합치기"로 합칩니다
- **24시간**: 첫 생성 시각이 모든 이어달리기 링크에 계승되고, 지나면 "종료된 방" 화면
